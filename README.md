### 🔧 What I'm working on

Building **Orkest** — a multi-tenant AI workflow platform where agent runs stop at human-in-the-loop approval gates before anything touches an ERP, HR or finance system. LangGraph for orchestration, Celery + Redis for async execution, Postgres with row-level security for tenant isolation, and pgvector-backed RAG for retrieval.

### 🏗️ Featured work

- **[Orkest](https://github.com/usamam46-git/Orkest-AI)** — multi-tenant AI automation platform for ERP, HR and finance workflows, built around human-in-the-loop approval gates (Python, LangGraph, Celery, Redis, Postgres/pgvector)
- **Healthcare Information Management System** — production healthcare platform serving 300,000+ users (Node.js, JavaScript, React)
- **Gym Management System** — full-stack gym platform with automated face-recognition attendance: a Python service reads RTSP streams from Hikvision cameras and feeds attendance back into the Node.js backend. Two deployments live with clients
- **[Frappe-Gymstack](https://github.com/usamam46-git/Frappe-Gymstack)** — gym membership app for Frappe/ERPNext v15: memberships, face-recognition attendance API, Stripe webhook receiver with idempotency, nightly payment reconciliation, and Entra ID SSO
- **[PulseBoard](https://github.com/usamam46-git/Pulse_Board)** — team collaboration platform for daily standups with real-time presence, AI summaries, and SaaS-grade auth and billing
- **[HikVision-AI-Scanning](https://github.com/usamam46-git/HikVision-AI-Scanning)** — Python facial-recognition pipeline against live Hikvision camera streams
